WTJ Uploader – Privacy Policy

Last updated: November 13, 2026

WTJ Uploader is used only by the owner of the YouTube channel "Welcome to Japan". It accesses that channel through the YouTube Data API and YouTube Analytics API, with the owner's permission, to upload videos, set thumbnails and captions, update video descriptions, and read the channel's own analytics.

Data we access

Only data belonging to the owner's own YouTube channel. No data from other users is collected.

How data is used and stored

Data is used only to publish and improve the owner's own videos. Access tokens and analytics reports are stored privately by the owner and are not sold, shared, or used for advertising.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

WTJ Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
